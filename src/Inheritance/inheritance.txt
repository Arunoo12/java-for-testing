// inheritance 
- Aquiring all properties (variables and methods) from one class to another is called inheritance .
// types of inheritance
1- single
2- multi level
3- hierarchy
4- multiple 

// single inheritance
- means one parent and one child

// multi level inheritance
- means one parent / one child / one grandchild/ grand grand child ......

// hierarchy inheritance
- means one parent can have child and child can also have child ...... so on continue

// multiple inheritance
- means multiple parents can have one child
